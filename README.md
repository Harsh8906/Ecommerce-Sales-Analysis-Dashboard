# E-commerce Sales Analysis Dashboard

## 📊 Project Overview

This project focuses on analyzing e-commerce sales data using **Python, SQL, and Power BI**.

The project includes data cleaning and preparation using Python, exploratory analysis using SQL queries, and an interactive Power BI dashboard to visualize key sales and business insights.

The dashboard helps analyze sales performance, profit, orders, products, categories, cities, payment methods, and order status.

---

## 🛠️ Tools & Technologies Used

- **Python** – Data cleaning and preparation
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **SQL** – Data analysis and querying
- **Power BI** – Dashboard creation and data visualization
- **Excel** – Data source

---

## 🧹 Data Cleaning and Preparation

The dataset was cleaned and prepared using Python. The process included:

- Checking the dataset structure and data types
- Identifying and handling missing values
- Checking and removing duplicate records
- Cleaning text columns and removing unnecessary spaces
- Converting columns to appropriate data types
- Handling invalid values
- Preparing the dataset for further analysis and visualization

---

## 🔍 SQL Analysis

SQL queries were used to answer important business questions, including:

- What is the total number of orders?
- What are the total sales?
- Which products generate the highest sales?
- Which cities have the highest sales?
- How do sales perform across different months?
- Which products generate the highest profit?
- What is the distribution of different payment modes?
- Which orders were cancelled?

## 📈 Power BI Dashboard

The interactive dashboard provides a visual overview of e-commerce business performance.

### Key KPIs

- **Total Net Sales:** 3.29M
- **Total Profit:** 658.24K
- **Total Orders:** 311
- **Average Order Value:** 10.58K

### Dashboard Insights

The dashboard includes:

- Sales by Month
- Sales by Category
- Sales by Product
- Sales by Payment Mode
- Sales by City
- Sales by Order Status
- Profit by Category
- Interactive filters for Month, City, and Payment Mode

---

## 💡 Key Business Insights

- The dashboard helps identify the best-performing products based on sales.
- Sales performance can be compared across different product categories.
- City-wise analysis helps identify locations contributing the most to sales.
- Payment mode analysis shows customer payment preferences.
- Order status analysis helps track delivered, returned, cancelled, and pending orders.
- Profit analysis helps compare the profitability of different product categories.
